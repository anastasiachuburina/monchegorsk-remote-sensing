# ДЗЗ-анализ природных и техногенных объектов района Мончегорска

## Описание проекта

Проект посвящен подготовке набора пространственных данных для анализа природных и техногенных объектов района Мончегорска и центральной части Кольского полуострова. Территория исследования характеризуется сочетанием природных ландшафтов северной тайги, болот, водных объектов и горных массивов с объектами горно-металлургического и горно-обогатительного комплекса.

## Цель проекта

Цель проекта — подготовить набор пространственных данных, дешифровочных эталонов и производных материалов дистанционного зондирования Земли для анализа природно-техногенных ландшафтов района Мончегорска.

## Использованные данные

В проекте использовались:

- снимки Sentinel-2 MSI;
- снимки Landsat;
- цифровые модели рельефа;
- тематические продукты земного покрова;
- высокодетальные изображения Google Earth Pro;
- граница территории исследования.

## Методы

В рамках проекта были выполнены:

- подбор и систематизация открытых пространственных данных;
- визуальное дешифрирование природных и техногенных объектов;
- описание прямых и косвенных дешифровочных признаков;
- выбор спектральных синтезов для анализа объектов;
- классификация снимка Sentinel-2 в MultiSpec;
- подготовка метаданных и картографических материалов.

## Основные классы объектов

В проекте рассматривались следующие классы объектов:

- карьеры;
- отвалы;
- промышленная площадка Кольской ГМК;
- загрязненные водные объекты;
- городская свалка;
- дороги;
- леса;
- болота;
- тундровые сообщества;
- вырубки;
- заброшенные территории.

## Структура репозитория

- `report/` — пояснительная записка к проекту;
- `metadata/` — описание исходных и производных данных;
- `data/` — пространственные данные проекта;
- `outputs/` — итоговые карты и иллюстрации;
- `docs/` — дополнительные материалы по дешифрированию и классификации.
